# YouTube Analysis Pro

This is a SaaS website project for YouTube analytics built with Next.js, TypeScript, and Tailwind CSS supporting both dark and light modes.

## Project Structure

```
YouTube-Analysis-Pro/
├── components/
│   ├── Layout.tsx
│   ├── Navbar.tsx
│   ├── Footer.tsx
│   ├── Dashboard.tsx
│   └── Charts/
├── pages/
│   ├── api/
│   ├── dashboard.tsx
│   └── index.tsx
├── public/
│   ├── images/
│   ├── favicon.ico
│   └── manifest.json
├── styles/
│   ├── globals.css
│   └── tailwind.config.js
├── types/
│   ├── analytics.d.ts
│   ├── user.d.ts
├── utils/
│   ├── api.ts
│   └── constants.ts
├── .gitignore
├── next.config.js
├── package.json
├── tsconfig.json
└── README.md
```
